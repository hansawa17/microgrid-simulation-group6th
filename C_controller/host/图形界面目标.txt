# PC-C 风力发电机监控与控制系统 GUI 设计总指令

## 一、整体设计风格

请生成一个用于**南极孤立微电网风力发电子站 PC-C 上位机**的工业监控 GUI。
整体要求：

- 中文界面
- 工业监控 / SCADA 风格
- 浅色背景，可以对小部分按键/状态等用协调的颜色渲染
- 清晰、简洁、专业/排版清晰
- 数据来源暂时先不是你要关注的，你只需要专注交互界面设计
- 适合 1920×1080 桌面显示器
- 显示系统标题和当前时间
- 显示通信与系统状态
- 重要运行状态使用明显的状态指示灯
- 不要设计成网页风格，不要过度装饰
- 强调**实时监控、远程控制、历史追溯、通信状态**

# 三、运行监控页面必须增加三个通信/设备状态

你刚才特别强调了这一点，我建议明确区分。

### ① PC-A通信状态

注意：**PC-C与PC-A之间的通信状态**。

```
PC-A通信

● 在线
```

例如：

```
TCP连接：正常
最后通信：20:15:03
```

---

### ② STM32状态

```
STM32状态

● 正常
```

这里不是简单表示 UART 是否连接，而是表示：

> PC-C是否能够正常收到 STM32 的状态数据。

可以进一步显示：

```
UART通信：正常
最后数据：20:15:03
```

---

### ③ PC-C自身状态

可以在状态栏显示：

```
PC-C：正常
```

其中：

- **PC-A在线**：TCP通信层状态
- **STM32正常**：STM32设备/数据状态
- **TCP正常**：PC-C ↔ PC-A通信接口
- **UART正常**：PC-C ↔ STM32通信接口

这样不会把“设备状态”和“通信状态”混在一起。

# 四、第二部分：实时曲线——风速与功率

实时曲线部分专门围绕：

```
timestamp
wind_speed
power_available
power_set
power_actual
```

来设计。
我建议这个板块内部放**两张曲线图**。

---

## 曲线①：风速变化曲线

标题：

> 实时风速曲线

横轴：

```
timestamp
```

纵轴：

```
wind_speed / m/s
```

数据点：

```
(timestamp, wind_speed)
```

显示最近一段时间的数据，例如最近 60 秒。

---

## 曲线②：风机功率变化曲线

标题：

> 实时功率曲线

横轴：

```
timestamp
```

纵轴：

```
功率 / kW
```

同一张图显示三条曲线：

```
power_available
power_set
power_actual
```

也就是：

```
可用功率
目标功率
实际功率
```

这样可以非常直观地观察：

```
风速变化
    ↓
可用功率变化
    ↓
EMS改变目标功率
    ↓
风机实际功率跟随目标
```

# 五、第三部分：参数设置

页面标题：

> 风力发电机参数设置

这个页面一定要明确**哪些数据可以被 GUI 修改，哪些不能修改**。

## 可修改参数

| 参数字段单位是否修改 |                         |     |   |
| ---------- | ----------------------- | --- | - |
| 切入风速       | `cut_in_speed`          | m/s | ✅ |
| 额定风速       | `rated_speed`           | m/s | ✅ |
| 切出风速       | `cut_out_speed`         | m/s | ✅ |
| 额定功率       | `rated_power`           | kW  | ✅ |
| 最大桨距角      | `deg_max`               | °   | ✅ |
| 控制周期       | `control_period`        | s   | ✅ |
| 通信超时       | `communication_timeout` | s   | ✅ |
| 控制模式       | `control_mode`          | —   | ✅ |

板块大体布局：

```
┌─────────────────────────────────────────────┐
│              风机参数设置                   │
├─────────────────────────────────────────────┤
│                                             │
│ 切入风速       [ 3.0       ] m/s            │
│ 额定风速       [ 12.0      ] m/s            │
│ 切出风速       [ 25.0      ] m/s            │
│ 额定功率       [ 1000      ] kW             │
│ 最大桨距角     [ 20.0      ] °              │
│ 控制周期       [ 1.0       ] s              │
│ 通信超时       [ 3.0       ] s              │
│                                             │
│ 控制模式       [ 闭环 ▼ ]                   │
│                                             │
│             [应用参数] [恢复默认]           │
└─────────────────────────────────────────────┘
```

# 八、第六部分：报警与通信

这个部分分为两个 Tab。

```
┌─────────────────────────────┐
│ [系统报警]   [通信日志]     │
└─────────────────────────────┘
```

---

## Tab 1：系统报警

对应：

```
system_log
```

表格：

```
时间 | 等级 | 类型 | 来源 | 描述
```

例如：

```
20:15:01 | INFO    | START    | GUI    | 风机启动成功
20:16:21 | WARNING | WIND     | STM32  | 风速接近切出值
20:17:32 | ERROR   | UART     | UART   | STM32通信超时
```

---

## Tab 2：通信日志

对应：

```
communication_log
```

表格：

```
时间
接口
方向
消息类型
周期
数据长度
结果
延迟
错误码
```

例如：

```
20:15:01 | TCP  | RX | wind_control | 101 | ...
20:15:01 | UART | TX | wind_control | 101 | ...
20:15:02 | UART | RX | wind_status  | 101 | ...
20:15:02 | TCP  | TX | wind_status  | 101 | ...
```
