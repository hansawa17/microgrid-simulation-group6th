# C 风电子站 · 陈信甫

- firmware/：真实 STM32 控制程序，Wi-Fi TCP 客户端连接 A；计算风机启停、桨距并回传。
- host/：Qt 上位机，通过串口与单片机交换状态、参数和模式，维护 wind.db。

首批任务：确认模块/固件与接线 → UART 收发与帧解析 → Wi-Fi 连接 A → 保护和桨距计算 → 上位机数据库/GUI。
中断接收缓冲，完整帧交主循环解析；用定时器或 HAL_GetTick 管理周期与超时，不在中断中进行长时间阻塞收发。
停止/保护优先级和失联行为须共同确认。B 的目标、A 的实际状态、单片机动作分别记录。
