# v1.0.2 发布说明

`v1.0.2` 是面向 2026-09-11 现场验收的修订版，不改变 TCP `version=1`、字段单位和 A/B/C 控制权。

## 修复与新增

- C 固件：ESP8266 上电软复位、连续失败自动复位、重入网、STA IP 确认、TCP 重建和 USART1 错误恢复。
- C 上位机：USB 串口短暂拔插后自动尝试重开原 COM 口。
- A：B/C 最后连接的断开/超时/错误写 WARNING 并触发非阻塞告警；断线注入可发送 TCP RST。
- A：可视化配置开始时刻、结束时刻、计算步长并重采样场景。
- B：合入远端 `2175ac5` 的供需平衡评分阈值，添加边界回归。
- 交付：新增最新评分表 50 项核对、现场演示、测试记录和四类要求文档。

## 兼容性

- A/B/C TCP 报文格式和数据库主语义不变。
- B 正式入口仍是 GUI 直持 TCP。
- C Wi-Fi 运行期端点仍仅存 RAM，重新上电使用编译期默认值。

## 验证和已知边界

- CPython 3.11.14 / PyQt6 6.11.0 环境全量执行 160 项 PC 自动化测试，0 failure，0 error。
- 发布机没有 ARM 交叉编译工具链，因此不宣称 STM32 固件已编译、烧录或实物通过。
- 三机局域网、ESP8266 断电/热点断开、USB 串口拔插、A 重启、高风禁运和完整闭环须按 `06-onsite-demo-runbook.md` 当场验证。
- 若 ESP8266 软复位命令也无响应，当前硬件未配置独立 RST 引脚，需重新给模组上电。
