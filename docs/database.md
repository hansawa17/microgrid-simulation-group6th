# 为什么实时数据仍需要数据库

数据库不是网络服务器，也不是只存“不会变化的数据”。它让计算、通信与 Qt 界面使用一致状态，并保留历史用于验收。

| 数据 | 更新方式 | 用途 |
|---|---|---|
| 参数与场景 | 初始化/人工修改 | 设备约束、风速与负荷曲线 |
| 当前遥测遥信 | 按设备/字段更新 | 最新实际状态、启停故障 |
| 目标与动作 | 带命令标识更新 | B 功率目标、C 桨距/启停；与实际值分开 |
| 历史 | 带时间追加 | 曲线、策略效果、回放 |
| 日志 | 事件追加 | 超时、非法报文、硬件断开 |

A 仅直接访问 grid.db；B 仅直接访问 ems.db；C 上位机仅直接访问 wind.db。跨电脑走报文，不共享数据库文件。
多个进程分别建立连接，事务保持短小；配置合理的锁等待策略。一轮状态更新尽量放在同一事务，避免界面读到半轮结果。
建议历史记录包含 session_id、step、sim_time_s、接收时间；指令包含来源、seq、状态与处理结果。

表结构尚未冻结，本文件不是 SQL 迁移。具体表及四遥点表由各模块负责人共同确认。数据库保存在 data/runtime/，不提交 Git。
