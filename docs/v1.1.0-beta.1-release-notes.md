# v1.1.0 beta1 发布说明

发布日期：2026-09-11

Git 标签：`v1.1.0-beta.1`

发布类型：预发布版（Pre-release）

## 本版改动

### A：GUI 与后台服务解耦

- 仿真计算循环和 TCP server 分别运行在两个独立 Python 进程中，GUI 只负责显示与控制。
- 关闭 A GUI 不再暂停数据库状态，也不再终止计算或 TCP 服务；重新打开 GUI 后自动读取原 `grid.db`、PID、端点与心跳状态。
- 每个 `grid.db` 的计算进程和 TCP 进程分别使用操作系统文件锁保证单实例。
- 增加 `python -m A_simulator services start/status/stop` 运维入口。显式停止计算服务会先安全暂停仿真；停止 TCP 不影响计算。
- Windows 下心跳 JSON 原子更新加入共享冲突短重试，监控文件竞争不会中断仿真进程。

### B：柴油机上下限立即约束下发策略

- 修复 B 已显示 A 的 `diesel_min_power_kw/diesel_max_power_kw`，但仍可能在最长一个旧调度周期内复用旧 decision 的问题。
- B 现在先保存 A 参数并重建 `DispatchConfig`，再处理新 state；参数变化立即作废旧决策并重算。
- 下一次 1 s 调度检查发送的非零柴油目标不低于 A 最小功率，上限为 A 最大功率减去 B 配置的备用容量 `reserve_kw`。
- 已存在的 `ems.db` 会执行当前 schema 迁移，同时保留人工配置值。

## 启动与升级

从旧版本升级前，先关闭旧版 A GUI 及其子进程，再更新代码并使用项目 Python 3.11 环境启动：

```powershell
.\scripts\start_a.ps1
```

查看或停止新版 A 后台服务：

```powershell
.\.venv\Scripts\python.exe -m A_simulator services status
.\.venv\Scripts\python.exe -m A_simulator services stop --role all
```

现有 `grid.db` 可继续使用。本版未改变 A/B/C TCP `version=1` 消息协议。

## 验证结果与边界

- 环境：CPython 3.11.14、PyQt6 6.11.0。
- PC 自动化测试：168 项通过，0 failure，0 error。
- 已覆盖独立后台计算、独立 TCP 响应、GUI 关闭不暂停及 B 新上下限实际进入自动下发入口。
- 未在本次发布机器重新编译或烧录 STM32，也未完成真实 A/B/C 三机、Wi-Fi、UART 和弱网现场验证；上述项目不能由 PC 自动测试替代。
